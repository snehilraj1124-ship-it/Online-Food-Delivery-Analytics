# 🍔 Online Food Delivery Analytics

## 📊 Project Overview

Online Food Delivery Analytics is an end-to-end business analytics project designed to analyze food delivery orders and generate meaningful insights about customers, restaurants, revenue, food categories, delivery operations, payment methods and order behaviour.

The project combines multiple technologies including **Python, Java, SQL, HTML, CSS and JavaScript** to demonstrate a complete data analytics workflow.

The dataset contains synthetic food delivery order records created specifically for educational and portfolio purposes.

---

## 🎯 Objectives

The primary objectives of this project are:

- Analyze food delivery order trends
- Measure revenue and order performance
- Analyze restaurant performance
- Understand customer behaviour
- Study popular food categories
- Analyze delivery performance
- Evaluate customer ratings
- Analyze payment preferences
- Compare city-level performance
- Analyze order status and cancellations
- Build an interactive analytics dashboard

The project uses a synthetic food delivery dataset containing approximately **1,500 order records**.

- Delivery Time
- Customer Rating
